Status icons & colors

  ●  Working   — cyan, spinner active
  ⧗  Input     — yellow, needs your attention (what prefix+u jumps to)
  ○  Idle      — gray, recently active
  ·  New       — dim, no tokens yet

Implementation approach

Width check in ui.rs render function. If frame.size().width < 100, call render_cards() instead of the existing table. Cards use ratatui List with 3-line ListItems. Selection highlight spans all 3 lines. No changes to session.rs, app.rs, or key handling.
